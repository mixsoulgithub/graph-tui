# 键位与交互

graph-tui 的全部按键、鼠标动作和 `:` 动词。`?` 里是精简版,这里是一份完整的。
键位可以重新绑定,文件格式与动作名见 [config.zh.md](config.zh.md)。

- 所有坐标都是终端单元格;光标是一个**格子**,不是"第几个框"。
- 光标格下面是框就选中框,是边就选中边,都没有就是空选。
- 改几何与改属性的动词要求 `1:1`:放大或缩小时会先切回 `1:1`、锚在光标上,再执行;状态行标
  `VIEW`(缩放后标 `VIEW 150%`,细节降低时还会标 `LOD`)。`:layout` / `r` 是例外,任意缩放
  都能跑。

## 谁先吃按键

优先级从上到下,上面的打开时下面的全部不响应:

1. 浮层:`?` 速查、`:e` 的文件选择器、右键菜单。
2. 底行输入:提示行(`:text` 打开,`Ctrl+G` 交给外部编辑器),以及 `:` 命令行、`/` 搜索。
3. 普通键位。

带 `Ctrl` / `Alt` 的组合只认下面列出来的那些,其余一律吞掉(不会退化成对应的单键)。

## 移动与选择

| 键 | 做什么 |
| --- | --- |
| `h j k l` / 方向键 | 光标移动**一格**;数字前缀是格数,`5l` = 向右五格 |
| `gg` | 光标回到原点的格子 `0,0` |
| `{x},{y}G` / `{n}G` | 跳到那一格(`100,100G`;这一对按 `x,y` 读,和状态行一样)/ 跳到第 `n` 行、列不变(`40G`);视图会以落点为中心,这次跳跃也会进跳转列表 |
| `Ctrl-d` / `Ctrl-u` | 半屏往下 / 往上跳,落到最近的节点 |
| `Ctrl-o` / `Tab` | 跳转列表后退 / 前进(记的是格子,不是框;它也会切标签页,所以 `gf` 打开另一个文件后马上按 `Ctrl-o` 会回到原处)。只要你*做了事*就会记一次跳转:新建框、改文字、改样式、搜索(`/`、`n` / `N`)、点击;纯光标移动不记,所以从任何地方按 `Ctrl-o` 都回到上次干活的地方 |
| `v` | 开始区块选择:锚点落在光标格(空格上也能起),移动光标扩大;框按矩形相交、边按可见格落在矩形里判定 |
| `Enter` | 打开光标下的**链接**;有未确认的区块选区时先**确认选区**(钉住另一端,之后移动光标不再改变它)。想恢复旧含义就把 `enter = confirm_selection` 绑回去 |
| `gf` | 打开光标下的链接(同 `Enter`);没有链接时提示 `no link under cursor`,**不会**退回 `F` 的铺满 |
| `Esc` | 有选区先取消选区;否则什么都不做(退出只认 `:q` / `:wq`) |
| `E` | 隔离:只显示**光标所在节点**、它的邻居以及碰到它的边,其余框、边、注释、点标签与区域全部不画,不是压暗。节点仍按原来的端口与路线绘制,所以画面不会跳。挪到可见邻居上,中心就跟着走;藏起来的元素点不到、选不中、也拾取不到。`E` 或 `Esc` 退出,一切恢复;光标不在节点上时只提示。开着时状态行保留 `isolate <name>` |
| `Ctrl-e` | 选边:光标压在节点上时,在接到这个节点的边里轮;叠了好几个框时先在框之间轮;光标不在节点上时按这一格的边候选轮 |
| `L` | 循环图层(全部 → 各层 → 全部);非当前层压暗 |
| `Ctrl-h j k l` | 把选中的框(没选区就是光标框)挪一格;也可以带数字前缀(`10` + `Ctrl-l` = 十格,一次撤销)。光标与选区跟着挪,光标出画面边距时视图跟过去 |

## 视图

| 键 | 做什么 |
| --- | --- |
| `+` / `-` / `0` | 放大 / 缩小(锚在光标上,每按一次 1.25,离 `100%` 6% 以内吸附)/ 回到 `1:1` 且**画面不动**;要回原点用 `gg`(画布无限,平移没有边界) |
| `f` | 把聚焦的分组(没聚焦就是光标节点的分组)铺满画面 |
| `F` | 铺满整幅图(最多到 `1:1`,不再放大) |
| `space` | 把光标格挪到画面正中 |
| `B` | 点节点名标注开关 |
| `w` / `b` | 从光标沿画面的主轴打一条射线(宽图向右、高图向下),跳到碰到的第一个**框或边**;`b` 反方向。射线跑到**整幅图**的边缘,不只是窗口,所以可能落到屏幕外,视图会滚过去;边在哪儿画出来都算一站(窗口内,因为笔画是在那里量的),窗口外则算第一个框。那条线上什么都没有时(表格状布局里常见)退回该方向上最近的框,所以只要还有框,这个键就不会什么都不做。那个方向彻底没有东西时只提示,光标不动 |
| `/` | 搜**文字**:节点名、别名与首字母、分组名、区域标题(命中分组或区域时也把它里面的框都收进来);只有命中的框变成搜索黄(点节点的标签也一样),画面其余部分保持原色。纯数字改为聚焦那个分组 |
| `n` / `N` | 下一个 / 上一个搜索命中(`E` 隔离藏起来的命中会跳过;所有命中都被藏起来时状态行会说明) |
| `r` | 在六套具体布局间循环(会产生一步撤销;`auto` 不在循环里) |
| `?` | 键位速查(任意键关掉) |
| `:q` / `:wq` | 退出 / 存盘后退出(`q` / `Esc` / `Ctrl-c` 都不退;`:wq` 存失败就不退) |

## 建图与编辑

| 键 | 做什么 |
| --- | --- |
| `i` | 只改**一个框:光标下的那个**。光标下有框:在**框里原地改文字**,插入点从光标所在字符开始(只有光标在文字外时才在末尾),打字时框跟着长,`Enter` 插换行,`Esc` 提交(一步撤销),`Ctrl-C` 丢弃草稿,完全不经过提示行;选中的是边:给这条边**建注释框**并进提示行(空框 `Esc` 或空回车就撤掉);什么都没有:在光标格新建框(压到别的框就往右让)并立刻开始编辑,没动过的新框按 `Esc` 会删掉。`point` 节点没地方放草稿,所以仍用提示行。已确认的区块选区会被拒绝(`select one box to edit`),不会把一段文字写进好几个框 |
| `:notes` | 边注释开关(已经没有默认键了)。关掉后注释框不画、不算障碍、不占尺寸、也点不到,边会重新布线 |
| `s` | 样式菜单:框给框型/边框色/填充/文字色/文字背景/对齐/图层;边给线型/方向/端口(起点 / 终点侧面)/拐角/颜色/分组/折点/图层。再次打开会回到上次选的位置 |
| `c` | 颜色菜单:框改边框色,边改边颜色(`auto` + 12 色,当前值打 `*`) |
| `S` | 在光标行与下一行之间拆开光标框:前一段留下,其余挪到右边的新框里(同样的样式/颜色/对齐/图层);边与注释留在原框。最后一行(`nothing after this line`)、`point` 节点和边注释上拒绝 |
| `M` | 把选中的框合并成一个:光标下的框(否则阅读顺序第一个)保留 id/位置/样式,文字按阅读顺序用 `\n` 连接,内部边丢掉,边界边改指到它;一步撤销。至少要两个框 |
| `y` | 把画面片段复制进剪贴板(框、文字、两端**都在选区里**的边,以及显式选中的边);文档不动 |
| `Ctrl+G` | 用 `$VISUAL` / `$EDITOR` 改光标框,退出时结果直接写回:一步撤销,不经过提示行(`edit_text_external`) |
| `d` | 剪切:框、文字以及所有碰到它们的边都删掉;剪贴板保留文字,加上两端都在选区里的边(边界边从文档里删掉,但不进剪贴板,所以粘贴永远不会造出悬空边)。整批会删光所有框时拒绝。光标留在原地。状态:`cut N boxes, removed M edges (clipboard: K)` |
| `p` | 把剪贴板里的东西粘到光标处(生成新 id,复用分组与图层);压到已有框就往右 / 下 / 右下错开,最多试 32 个位置 |
| `e` | 两段式连边:源(选区或光标框)-> 选目标 -> `Enter` 建边,`Esc` 取消;源和目标可以是同一个框(自环)。新边复制你最后选中过的边的分组/线型/拐角/颜色(区块选区同样不算) |
| `u` / `Ctrl-r` | 撤销 / 重做 |
| `Ctrl-t` / `Ctrl-n` / `Ctrl-p` / `Ctrl-w` | 新标签页 / 下一个标签页 / 上一个标签页 / 关闭标签页 |
| `R` | 从磁盘重新载入源文件(见*外部改动*);有未保存改动时第一次只警告,第二次才丢 |
| `:` | 命令行(动词见下) |

提示行(`box: ` / `text: ` / `link: `)和 `:` 一样独占整行,从最左边开始,盖住模式标记与
节点名。它由 `:text` 打开(建框时是 `:new`);`i` 的原地编辑从光标所在字符开始,所以改名
就是编辑,不用重打。

提示行、`:` 命令行和 `/` 搜索这三条可编辑行共用一个行编辑器,带常见的 emacs 键与词移动:

| 按键 | 动作 |
| --- | --- |
| `←` `→` / `Ctrl-B` `Ctrl-F` | 左 / 右一个字符 |
| `Alt-←` `Alt-→` / `Alt-B` `Alt-F` | 左 / 右一个词(`M-b`/`M-f`;词是非空白的连续段,所以 `out/x.gtui` 一步走完) |
| `Home` `End` / `Ctrl-A` `Ctrl-E` | 行首 / 行尾 |
| `Backspace` `Delete` `Ctrl-D` | 删光标前 / 光标处 / 光标处的字符 |
| `Ctrl-K` / `Ctrl-U` | 删到行尾 / 删到行首 |
| `Ctrl-W` / `Alt-Backspace` | 删光标前的一个词 |
| `Ctrl-G` | 把提示行交给 `$EDITOR`(只限提示行) |

打字插在光标处;`Enter` 提交,`Esc` 丢弃。

原地编辑(`i`)沿用同一套词键:`Alt-←` / `Alt-→` 一次走一个词,`Alt-Backspace` 删光标前的
一个词。`Enter` 换行,`Up` / `Down` 在草稿里按列移动,`Esc` 提交,`Ctrl-C` 丢弃。

### 把一个框拆成几个

在文字提示里输入 `<|new box|>` 会拆框:记号前面的文字留在原处,后面每一段变成一个新区。
新框依次放在前一个框右边,顶部对齐,隔一格;位置被占就往右让(再不行下移一行)。它们复制
源框的样式、边框色、填充、文字色、文字背景、对齐与图层。光标留在原框上,边与注释绑定都不动,
整个拆分是一步撤销。空段会丢掉,所以 `<|new box|>a` 和 `a<|new box|>` 都不会多出框;非空段
少于两段时什么都不写,状态行提示 `nothing to split`。想写字面记号就写 `\<|new box|>`(反斜杠
会留在文字里,免得以后再编辑又被拆)。只有单个普通框会拆:区块选区、边注释和 `point` 节点
把记号当普通文字,`:text` 与 headless 的 `text` 操作永远不拆。

拖拽连边时(从框上右键拖、从边框左键拖,或 `e` 模式),会有一条虚线预览跟着指针:指针下有框
就连到那个框(框会高亮),否则连到光标格,所以你始终看得到边会去哪儿。预览不碰文档、不盖住框、
也不消耗撤销步。

`i` 编辑时只有一个光标:终端光标,移到草稿当前所在的格子(画面本身从不画第二个)。

`Ctrl+G` 把文字交给 `$VISUAL` / `$EDITOR`(都没有就用 `vi`)。有两个地方用它,而且两处
编辑器结果都是**立即应用**,不需要再按 `Enter`:

- **普通模式**(`edit_text_external`):光标框(或整个选区)写进临时文件。保存退出后,文字
  直接写进框,算一步撤销,不经过提示行。`<|new box|>` 在这里也生效,所以上面的拆分规则同样
  适用。
- **提示行里**(`:text` / `e`):把提示行内容交出去,退出时按 `Enter` 同样的方式提交
  (`link:` 目标不接受换行,保留原行)。没改(`:q!`、直接退出)算取消;退出码非 0 或写回
  非法 UTF-8 / CR / NUL 都保持原样并说明原因。

`:` 命令行和 `/` 搜索词是单行语义,`Ctrl+G` 在那里只提示。编辑器必须**阻塞**:GUI 编辑器要
自带 `--wait`(`code -w`),否则内容相同会被当成取消。`$EDITOR` 是 `true` / `false` / `:`
时按未设置处理(工具常拿这些当占位)。

文字可以多行(`\n`):紧框按行数长高、按最长行长宽,markdown 的 `**粗体**` / `*斜体*` 与对齐
逐行生效;点节点只有一个名字(画在节点旁边的空位上)。文字还可以带链接:`[label](target)`
只显示 `label`,带下划线,target 不占宽度;在上面按 `Enter` / `gf` 打开。认识的 target 有
`http://`、`https://`、`mailto:`、`file://`、`self`、`~/…`、`./…`、`../…`、`/…`
以及任何其他 `scheme://`(走 `[links]` 配置,见 `config.md`;没有条目的 scheme 只提示
`no handler for scheme …`,什么都不跑);其他形式(`[x](notes.md)`、`javascript:…`)仍是普通
文字。链接不能嵌套,也没有专门的链接颜色(只有下划线),所以搜索黄与选区仍然读得出来。本地
`.gtui` 链接会在 graph-tui 里开成另一个标签页(那个文件已经打开就直接跳过去);`.dot` 链接
也开标签页;其他本地文件交给 opener(`[prefs] opener`、`$OPENER`,否则 `opener` /
`xdg-open`),当助手说 `edit` 时把终端交给它(`nvim` 接管屏幕,退出后 graph-tui 回来)。

target 可以带**位置**后缀 `right:line,column`:

| target | 含义 |
|---|---|
| `[code](./src/app.rs:10,4)` | 本地文本:第 10 行第 4 列(1 起,像 nvim 的 `gf`),直接用 `$VISUAL` / `$EDITOR` 打开,不走 opener,所以光标会落到位置上;不是 vim 的编辑器只能拿到行,状态行会说明 |
| `[here](self:10,4)` | 本文档:光标跳到格子 `10,4`(0 起,和状态行一样),不开新标签页 |
| `[other](./other.gtui:10,4)` | 一个 `.gtui`:切到它的标签页(没有就开一个)并跳到格子 `10,4`;`self`/当前路径永远不会开第二个标签页 |
| `[x](https://host/a:10,4)` | URL 从不带位置:`:10,4` 是 URL 的一部分 |

`.dot` 链接忽略位置(导入文件没有稳定的格子坐标)。每一次从链接发起的跳转都会记进跳转列表,
所以 `Ctrl-o` 能跨标签页回到你原来的地方。

记号只在**节点文字**里解释:`:` 行、`/` 搜索和提示行都是原始文字,所以 `/examples/` 或
`*a*b*` 在那里不会丢字符(光标按原始宽度数)。

## 命令行补全

`:` 输入时按 `Tab` 补全,`Shift-Tab` 往回;状态行上方会弹出候选浮窗,当前那个反显。

- 还没打空格:补**动词**(`fi` + Tab → `fill`)。
- 打了动词:补它的**取值**,例如 `box` 的 6 种框型、`style` 的 3 种线型、`dir` 的 4 种方向、
  `corner`、`head`、`textalign`、`layout`、`lang`、`notes`、`rotate`、`cycle`。
- `layer` / `tolayer` 补图层名;`link` 补框的 id 与文字。
- `e` / `w` / `save` / `export` 补**真实路径**:参数是整行剩余部分,所以带空格的名字能保住
  (`:w /tmp/a b.gtui` + Tab 两个词都在)。目录排在前面并以 `/` 结尾,所以 `Tab` 能走进子目录;
  `~/` 有效。`e` 只列 `.gtui` / `.dot` / `.canvas`,`w` / `export` 列全部。隐藏项要先打一个
  `.`。文件系统只在按 `Tab` 时扫描,渲染时从不扫。
- `:w` / `:wq` / `:save` 不带参数时:按 `Tab` 把默认存盘路径(绝对路径)整段填进去,还能接着
  改。空白文档得到的是 "no default path",不是猜一个。
- `text …` 这种自由文字不补。继续打字会收起浮窗,再按 `Tab` 重新按当前前缀筛一遍。

`:w` / `:e` / `:export` 正在输入时,状态行右侧会显示目标:解析后的绝对路径、`.gtui` 源加
`(overwrite)`、导入源加 `(source .dot stays untouched)`。放不下就从左边截断,保住文件名,
绝不碰输入内容或光标。

## 选区与组操作

`v` 拉出一块矩形,`Enter` 确认;确认之后移动光标不再改变选区,命令作用于选区里的**所有**框
和边。

- 状态行:`selection N boxes M edges · Enter to confirm` / `· confirmed`。
- 选中的框和边都用**红白呼吸**闪烁(和光标同一个相位),不铺底色;范围另有连续的灰边。
- 选区里的东西都没了(比如把选中的框删掉、或撤销掉),选区会自动取消,和点选区外面一个效果。
- 未确认时,所有改文档的命令(`d` / `p` / 样式动词 / `Ctrl-hjkl`)都会被拦下,回显"先按
  Enter 确认选区",不压撤销。
- 已确认时:
  - `d` / `:del`:删掉所有选中框和边,一步撤销,内容进剪贴板;
  - `box` / `nodecolor` / `fill` / `textcolor` / `textalign` / `text`:作用于所有选中框;
  - `style` / `edgecolor` / `dir` / `corner` / `via`:作用于所有选中边;
  - `Ctrl-hjkl`:只挪选中的框(选区里只有边时报"没有可移动的框");
  - 每种组操作整批只压**一步**撤销。
- 删除后选区清除;撤销/重做也会清除选区。

## 剪贴板

- 单槽,只活在这个会话里;不写系统剪贴板、不写 `.gtui`、不跨进程。
- 每次成功删除才替换内容;删除被拒、空删除、剪贴板为空时粘贴都不动它。
- `p` 按 `光标 - 剪贴板原点` 平移粘贴(原点只看框和文字,不看边),框、文字、边都生成新 id;
  落点压到已有框时依次试 `右移一整份 +1`、`下移一整份 +1`、`右下`、继续放大,最多 32 个
  候选。粘完光标落到第一份新框上、选择也指向它;分组按 id/label 复用(没有就新建),
  两端都在剪贴板里就改新 id,另一端还在就保留,端点没了就跳过并计数。
- 撤销/重做不改剪贴板。

## 撤销与重做

快照式:每步存一份改之前的文档。

- 上限默认 200 步(命令行 `--history N`);
- 同一值重复设置不算一步;一次拖拽整段算一步;`Ctrl-hjkl` 每按一次算一步;
- 缩放、平移、聚焦、搜索、图层、开关标注这些**只改视图**的动作不进栈;
- 撤销后再做新动作会清空重做栈;`:e` 打开另一份文档会清空两边;
- 撤销/重做不要求 `1:1`(恢复的是模型,不是几何编辑)。

## 鼠标

| 操作 | 做什么 |
| --- | --- |
| 左键双击(空处) | 和按 `i` 一样:弹"新建节点"的输入框,回车就在那儿建一个(默认样式 `none`) |
| 左键点 | 光标**立刻**落到点击的那一格(不吸到节点的角上);格下有框就选框,有边就选边;同一格压着好几条边时,连点就在它们之间轮。已有选区时:点选区**里面**保留,点**外面**取消 |
| 左键按在节点**边框**上拖 | 连边:在另一个框上松手就建边(不用回车;一步撤销;松在空处取消;只是点一下仍然只放光标)。只有带框节点有边框,`none` / 点节点仍用 `e` |
| 左键按在节点**内部**拖 | 挪这一批框(在选区里就整批挪),**任意缩放**都能用(不切回 `1:1`);光标与选区矩形按同样的画布位移走,矩形在松手前隐藏,整段拖动算**一步**撤销。2x 时一个画布格占两个鼠标格,0.5x 时一个鼠标格跳两格 |
| 左键按在选中边的**端点**上拖 | 重新接这一端:在另一个框上松手就改 `from` / `to`;颜色、分组、样式与注释保留;空处取消 |
| 靠近视口边缘拖 | 拖拽时自动平移(拖得越远滚得越快,每次事件最多 3 格) |
| 左键按在空处拖 | **拉出区块选择**:按下的那格是锚点,灰边跟着走;**松开左键就是确认**(回显报框/边数)。只是点一下不算拖动,圈到空处会自动丢掉。已经有一块选区时再拖,旧的那块直接换掉 |
| `Ctrl` + 左键拖 / 中键拖 / 在空处或边上右键拖 | 平移(右键拖要移动 2 格;原地不动的右键是菜单) |
| 从框上**右键拖** | 把这个框连到你松手的框(任何框型,包括 `point` / `none` 及其文字)。松在空处取消;松在源自己身上是自环;移动不到两格就是普通的菜单点击。配置里 `mouse_edges = false` 会关掉这个手势:右键拖就成了到处平移,一行高的 `none` 节点老被误连时这是出路 |
| 滚轮 | 以指针为锚缩放(每档 1.1);`Ctrl` + 滚轮平移 |
| 右键 | 在**按下**的那一格弹动作菜单:松开时没拖动才打开,所以按下本身不会弹菜单 |

重叠的边一条盖一条地画(没有 `┼` 接点):格子显示最上面那条边自己的笔画,被盖住的那条就到
那里结束。先画的边在上面;拾取一条边(在它覆盖的格子上反复点击轮选,或 `Ctrl-e`)会把它抬到
最上面。

按右键后要等它动:不到两格算点击,松开时在按下的格子弹菜单。两格以上就按按下的格子决定:
框就从它开始连边,其他(空处、边)就平移视图;即使拖回来也不弹菜单。菜单已经打开时,右键
只取消它,不动视图。中键拖与 `Ctrl` + 左键拖的行为完全没变。

菜单是**预览式**的:弹出的那一刻就把第一项套在元素上,鼠标划过 / 键盘上下移动时实时切换预览。
**一次左键**(或一次回车)才真正应用,应用时只产生一步撤销;取消或点菜单外会把文档原样回滚。

- 左键点菜单项 = 应用;点菜单外 = 关掉并回滚;右键 = 关掉并回滚;
- 键盘 `↑ ↓`(或 `j k`)在**当前这一层**里选;
- `l` / `→` = 进下一层菜单(当前项不是子菜单就什么都不做);`h` / `←` / `Esc` = 回上一层,
  顶层就关掉;
- `Enter` = 应用当前项(子菜单项则是进去);数字键直选第 n 项并应用;
- 菜单按种类(框 / 边 / 颜色)**记住自己的栈**:再按 `s` 会直接回到你上次走过的路径,光标停在
  上次选的那项,`h` 在每一层回到你进来的那一项(不再重置到第一项)。所以重复改颜色就是 `s`
  再 `l`/`Enter`;当前颜色打 `*`(并会预览);
- 预览不会进撤销栈,也不会改光标位置(应用时按弹菜单那一刻的位置)。

菜单内容按光标处的东西给:

- 框:框型(6 种)、边框色、填充、文字色、文字背景、对齐、图层、删除;
- 边:线型、方向、端口(`from_side` / `to_side`:auto / left / right / up / down)、拐角、
  颜色、清掉折点、删除;
- 空白:新建框…、居中。

每一项执行的都是对应的 `:` 动词,所以纯鼠标也能走完"选元素 → 改样式 → 存盘"。

## 动词

命令行以 `:` 打开,回车执行。改文档的动词都会产生一步撤销。

| 动词 | 作用 |
| --- | --- |
| `:new <文字>` | 在光标格新建框(不给文字就用新框 id);它复制你最后选中过**或改过样式**的框的样式、颜色与对齐(`s` 菜单 / `:box` / 颜色改动都算选中,光标移走也不丢),区块选区生效时除外 |
| `:link <目标>` | 从光标框连边到目标(id 或唯一的文字);键盘连边入口是 `e`,这个留给精确指目标 |
| `:del` | 删光标框(连文字与边);选中边时删那条边(等于 `d`,剪贴板带边) |
| `:box point\|none\|single\|rounded\|double\|heavy` | 框型(`none` 不画框也不画节点字形,只有文字;它也是默认样式)。切换时**文字**留在原地、框围着它变形:`none` 变成真正的文字节点(和它一直是 `none` 的画面相同),`point` 把字形放在第一个字符上,带框样式围着文字长。**新**框复制你最后选中过、或刚用 `s` / `:box` / 颜色动词改过样式的框的样式、颜色与对齐(区块选区不算) |
| `:nodecolor <#rrggbb\|auto>` | 边框色 |
| `:fill <#rrggbb\|none>` | 框内填充 |
| `:textbg <#rrggbb\|none>` | 文字背景(只铺在字上;和框的填充、边的背景互不影响) |
| `:edgebg <#rrggbb\|none>` | 边的背景(只铺在这条边经过的格子上) |
| `:textcolor <#rrggbb\|auto>` | 文字颜色 |
| `:textalign <left\|center\|right>` | 框内文字对齐 |
| `:text <余下整行>` | 光标框的文字(整行原样收下,`**粗体**` / `*斜体*` 照吃);光标在边上时改的是这条边的**注释框**,空串 = 连框一起删 |
| `:style <solid\|dashed\|dotted>` | 选中边的线型 |
| `:dir <none\|forward\|back\|both>` | 选中边的方向 |
| `:corner <rounded\|sharp>` | 选中边的拐角 |
| `:head <auto\|ascii\|arrows\|triangles>` | 选中边的箭头字形(`auto` 跟 `--arrow` / `[prefs] arrow` 走) |
| `:edgecolor <#rrggbb\|auto>` | 选中边的颜色 |
| `:group <id>` | 把选中的边换到那个分组 id |
| `:via <x,y x,y\|off>` | 选中边的手工折点(画布坐标);会让边在刚走过的那一行或列上折返的点会被跳过 |
| `:layer <名字\|all>` | 只看 / 只动这一层 |
| `:tolayer <名字>` | 把选中的节点移到这一层 |
| `:notes [on\|off]` | 边注释开关(默认开;不给参数就是切换;没有默认键,想要就在配置里绑 `toggle_notes`) |
| `:relabel [all]` | 把注释框重新贴回它那条边旁边(不给参数只动选中的注释框) |
| `:rotate [auto\|0\|90\|180\|270]` | 转方向:不给参数 = 顺时针 90 度;`auto` 交回自动选择(下次 `r` 生效) |
| `:layout <auto\|geo\|relax\|force\|layered\|tree\|chain>` | 换布局(`auto` 按结构挑;`r` 在六套具体布局间循环) |
| `:side <倍数>` / `:cycle <倍数\|auto>` | 方向选择的两个调参(格子光标下不再参与移动) |
| `:lang <zh\|en>` | 界面语言 |
| `:w [路径]` / `:save [路径]` | 存盘;不给路径写当前文档,`.dot` 来源写同目录 `<stem>.gtui` |
| `:e <路径>` / `:e` | 打开另一份文档(不存在的 `.gtui` 会像 `nvim newfile` 一样开成新文件)/ 弹出选择浮层(输入过滤、`↑↓` 选、回车打开、`Esc` 取消) |
| `:fromside [auto\|left\|right\|up\|down]` | 钉住选中边离开的侧面 |
| `:toside [...]` | 钉住它到达的侧面 |
| `:port from=<side> to=<side>` | 一次设两边(哪个键都可以省略) |
| `:tabnew [路径]` / `:tabs` | 开一个标签页(空白,或给定文件)/ 列出标签页,当前那个打 `>` |
| `:tab <n>` / `:tabnext` / `:tabprev` | 按编号切标签页 / 下一个 / 上一个 |
| `:tabclose [!]` | 关闭当前标签页;有未保存改动时拒绝,`!` 丢弃 |
| `:region new [标签]` | 用选中的框(或光标下的框)建一个区域 |
| `:region add [id]` / `:region rm [id]` | 把选中的框加进 / 移出区域 |
| `:region del [id]` | 删掉区域,保留它的框 |
| `:region collapse [id]` / `:region expand [id]` | 隐藏 / 显示成员(只影响显示) |
| `:region label <文字>` / `:region color <c\|auto>` / `:region style <s>` | 改光标框所在区域 |
| `:region` | 列出区域与成员数 |
| `:e! [路径]` | 强制作废本地改动、从磁盘重载(`R` 确认后也一样) |
| `:export <路径>` | 导出 `.svg` / `.png` / `.canvas` / `.dot`(有损) |
| `:export-canvas <路径>` | 同上,写 JSON Canvas |
| `:undo` / `:redo` / `:history` | 撤销 / 重做 / 报还能撤销和重做多少步 |
| `:q` / `:quit` | 退出(不存盘) |
| `:wq [路径]` | 存成 `.gtui` 再退出;存失败(没文件名 / 不是 `.gtui`)就留在原地 |

路径开头的 `~` 会展开,写之前自动建父目录。

### 外部改动

源文件在每次空闲轮询时检查一次(一个 `stat`,大约每秒 4 次)。大小或 mtime 变了就:

- **没有本地改动**:用磁盘上的版本替换文档,状态行会说明。解析失败的文件(正在被写)不会
  反复重试,而是退回下面的警告。
- **有本地改动**:什么都不替换。状态行右侧一直显示
  `file changed on disk: R reloads (drops edits), :w overwrites`,直到你动手:`R`(按两次,
  第一次只警告)或 `:e!` 重载,`:w` 覆盖文件;你自己的编辑不会清掉警告。
- **文件被删**:警告说源没了:`R` 会失败,`:w` 会重新创建。

## 光标与状态行

- 键盘移动光标像 nvim:视图不动,直到光标碰到两格边距,之后每一步都**立刻**把画面滚一格
  (没有缓动),同时光标**钉在它那条屏幕行上**:逻辑格继续前进,光标底下没有东西在动。跳跃
  (搜索、`n` / `N`、鼠标点击、`Ctrl-o` / `Tab`)仍然有动画;鼠标拖拽、`Ctrl` 拖平移与拖拽
  自动平移不变。
- 滚动与平移只**平移**画面:边走线是对整份文档做的(每个节点都是障碍,连视口外的格子也保留
  "这格已经有笔画"的状态),所以节点离开屏幕后笔画形状不变,画面上剩下的部分继续画。
- 交互模式用**终端真光标**:停在光标格(没有框时也在格上);`:` / `/` / 提示行打开时落到
  输入行末尾;浮层打开时隐藏。
- `--drawn-cursor` 改成把光标画进画面:点节点实心 `●` / `◉`,框节点边框走呼吸色。`--dump`
  与导出总是画进去。
- 边接到带框节点时:起点边框画 `┬ ┴ ├ ┤` 接点,终点把箭头嵌进边框那一格;点节点的箭头落在
  节点前一格。
- 箭头(`> < ^ v`)永远画在所有非节点元素**之上**:别的边穿过那一格时箭头保留自己的颜色,
  而且一格最多一个箭头(先画的边赢,除非有抬起的边:选中的边或被 `E` 点亮的边)。
  抬起的边在它自己的格子上还会**赢走字形**:如果别的边的箭头正好落在选中边经过的地方,那一格
  显示选中边的笔画,所以选中的边永远不会看起来是双向的。
- 边端口是**固定锚点**:按节点文字量,只有一条边(或三条以上)的侧面用中间锚点,两条边用
  最靠中间的两个,一个侧面最多用两个。所以加边、改框样式或缩放都不会挪动其他边。
- 一格只显示一条边的笔画;抬起的边(选中的边,或被 `E` 点亮的每条边)会重新占回自己的格子,
  所以高亮的边穿过别的边时仍然连续。
- 选中的元素用**红白呼吸**标出来,不铺底色:框节点闪它的边框,点节点闪它的名字/字形。
- 区块选择另有一圈连续灰边;区块里被框住的元素用反显区分。
- 还在等后续的键(`12`、`100,100`、`g`)显示在**底行右端**,像 nvim 的 `showcmd`;`Esc` 或
  任何无关的键都会丢掉这个序列。
- 终端至少 8 行时,底部是**两行**(更矮就退回一行):上面是状态行,左边
  `[2/5] ~/proj/x.gtui *   NORMAL   100%`,右边是工作目录与光标格 `x,y`
  (`~/proj | 1,4`);下面是命令行/输入行、最后一条消息或错误,以及右边 `:` 的路径提示。
  错误留到下个动作。模式标记是 `NORMAL` / `SELECT` / `LINK` / `COMMAND` / `SEARCH`。
  输入时上面那行仍然显示文件(并切到 `COMMAND` / `SEARCH`)。路径放不下时从左边截断,
  保住文件名;然后丢工作目录,再丢模式。`--dump` 与导出不占这两行。
